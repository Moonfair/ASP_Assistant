# 阵容页签

目标：玩家随时创建、保存、编辑阵容并分享，独立于当前游戏、OCR 和禁用状态。

实现选择：沿用 WPF + MVVM。侧栏新增阵容列表页签，标题下的全局新建按钮打开独立、非模态编辑窗口，避免窄侧栏容纳复杂表单，也允许查看其他页签。嵌入式编辑会挤占列表；模态窗口会阻断其他操作，故不采用。

阵容包含名称、作者及 1–10 个不重复干员。编辑草稿可以为空；保存需要名称、作者和至少一名干员。每名干员有独立的叠层核心、输出核心开关，允许兼任，每种核心不限人数；两个装备槽均可空、可清除，允许相同装备。以上未指定细节为实施默认值。

列表显示作者、人数和成员摘要，支持编辑、删除、导出文本及剪切板导入。导入先打开独立草稿，保留作者，保存后生成新条目；不会覆盖原阵容。关闭未保存编辑需提示。分享采用版本化、中文可读 JSON 文本，严格验证人数、重复干员、未知名称、版本、字段类型及长度。装备引用当前目录名称，不新增账号或网络服务。

本地数据位于 %APPDATA%/ASPAssistant/lineups.json，采用临时文件替换。保存失败保留草稿与已有列表，读取失败显示错误且禁止覆盖原文件。旧目录已下架的名称仍保留在本地阵容中，编辑时可移除或替换。剪切板失败显示提示，文本框允许手动复制/粘贴。

验证：分享往返与恶意/错误输入；10 人上限；双核心和双装备；草稿隔离；持久化与失败保护；WPF 真实绑定、窗口和最窄侧栏布局；完整现有测试回归。

## 头像与拖放编辑修订

根据用户截图改为左侧目录、右侧阵容头像和右下方统一编辑区。左侧干员/装备页签切换，图标宫格每行 3–4 个；干员复用完整筛选规则（含本局状态），装备按名称、等阶、类型筛选。筛选状态在页签切换时保留。

拖动干员进入右侧区域可加入阵容，双击/按钮也可加入。点击阵容头像选择编辑目标，下方唯一编辑区展示资料、双核心和两个装备槽；移除当前选中干员时自动选相邻干员。干员与装备头像读取现有本地图标，缺图时保留名称/占位。

装备可拖到干员头像上填入首个空槽，已满时显示提示不覆盖；直接拖入指定装备槽可替换。干员头像居上，两个更小的装备图标在下方呈品字型，各自右上角有清除按钮。仍支持下方选择装备和键盘操作。

验证重点：完整筛选和已选排除联动、拖放类型校验、满员/满装备、目标选择与清除、不修改别的干员、保存分享兼容、真实本地图标与最小尺寸布局。
