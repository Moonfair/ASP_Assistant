# 鲍勃随机语音与侧窗不透明度

在主干为现有设置页增加两个滑块，沿用 WPF 和 SettingsManager，不增加依赖。

- 随机语音间隔：10～120 秒，默认 15 秒。实际战备闲聊等待时间在设置值到两倍设置值之间随机选择；默认仍为 15～30 秒。修改后重新安排闲聊，不清除事件语音去重状态。语音总开关关闭或文件缺失时禁用滑块。
- 侧窗不透明度：20%～100%，默认 100%。实时影响整个侧窗，包括外扩筛选区域；保留 WindowChrome 和缩放手柄。使用 WPF 原生透明窗口和 Window.Opacity。
- 两项独立持久化，启动时恢复。缺失或损坏设置使用旧版默认值；保存使用现有临时文件替换机制。

实现选择：连续滑块比固定频率档位更易精确调整；Window.Opacity 作用于整窗，比逐个修改背景画刷更符合“不透明度”的含义。初步的 Win32 统一 alpha 方案被原生窗口测试证实受 WPF HwndTarget 的窗口样式保护拦截，因此采用 WPF 支持的 AllowsTransparency。范围和控件形式为本次实现选择。

验收：设置可操作，修改即时生效，重启保留；随机语音仍仅在战备阶段触发，事件语音优先级和去重保留；原生窗口启用透明合成，不透明度作用于 Window，100% 完全不透明，调整尺寸保留设置。
