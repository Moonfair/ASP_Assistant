# 可切换的侧边筛选布局

依据用户确认的 A 小图标版效果图实施：左侧外扩筛选栏，展开时保持主列表宽度与右边缘位置，收起仅保留入口和有效条件数量。保留原顶部筛选布局，通过顶部“侧边筛选”开关切换，默认顶部，记住上次选择。干员和装备共用布局选择；追踪和阵容页不显示筛选栏。

盟约使用已验证的 PRTS 透明原图，筛选标签 16px、摘要及卡片 13px，图标随文字颜色显示，缺图退回纯文字。筛选数据与控件复用，切换布局、页签、展开状态不清空已选条件。侧栏独立滚动，列表滚动不自动收起侧栏。筛选区提供重置和已有手动录入/清除禁用功能。
