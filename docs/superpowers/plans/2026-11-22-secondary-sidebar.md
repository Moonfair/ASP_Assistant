# 次级侧栏改版

接续 7c110e2，在同一 worktree 重构「更多」下五个页面。沿用现有 WPF、深色主题和 8 DIP 外边距。不变更游戏数据获取、匹配服务、阵容存储和编辑器。

- 敌人：领袖与战场可以手选；两个回合单独切换，不再滚过上一回合全部地图；各回合独立记住站位，新局复位。
- 阵容：新建、导入和分类是常用入口；资料库工具和卡片管理降级但仍可达。
- 匹配：稳定的页面标题与动态状态分离，将必填偏好、可选项和下一步操作分开；不改变房间状态机。
- 数据和调试：数值与等待读数区分；概览/明细分层，长诊断输出默认折叠。
- 验收：离线 WPF 场景，对照 280/310/400 DIP 的内容宽度与主要控件；回归手选、状态切换和现有业务测试。截图采用同一组样例，明确不是真实对局。
