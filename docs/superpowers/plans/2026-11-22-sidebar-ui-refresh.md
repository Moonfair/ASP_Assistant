# 对局侧栏改版 · 实施与验收

目标：在 280–400 DIP 的 WPF 主面板中，让玩家不离开对局就能查名称、追踪目标、读回合与经济。不改识别来源、游戏读数、阵容数据或网页版。

1. 主导航：保留 MainTabs 和每页实例；前三页常驻，其余通过「更多」选择。菜单和程序跳转均反映当前页，切换后保留搜索与筛选。
2. 浏览：两个目录共用带提示和清除动作的搜索框；无匹配时给出下一步。两种卡片均将名称、追踪放第一行，版本切换和详情放第二行。保留干员禁用和虚拟列表。
3. 追踪与状态：长名称使用整行，空清单提供跳转；取消全部保留二次确认。保留五项 HUD 指标及无数据占位，区分主要读数与辅助读数。
4. 验收：先写 WPF 交互断言，验证原版失败，再改实现；检查最小、默认和最大宽度、程序跳转、两类目标的增删与空态。渲染实际 WPF 控件并对照基线图，最后运行解决方案测试。

工作区保持隔离，不复制原目录未提交改动，不自动合并。
