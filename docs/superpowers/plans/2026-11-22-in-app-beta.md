- 保留现有工作树，在主干整合独有提交和未提交的工程文件。以合并前后的测试和 Git 祖先关系复核。
- v3.8.11 从 v3.8.10 分出，沿用旧版识别的 Windows x64 ZIP，不夹带主干新玩法。正式版的启动检查和普通检查不读取 Beta 清单。
